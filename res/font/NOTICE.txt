Bundled fonts
=============

tinos.ttf
  Tinos, from the Croscore font family (Google).
  Licensed under the Apache License, Version 2.0.
  A metric-compatible monospace face designed as a system substitute for
  Courier New. Used here as an extra terminal typeface because the platform
  default is Roboto Mono, which looks noticeably different at small sizes.

opensans_condensed.ttf
  Open Sans SemiCondensed SemiBold, from the Google Fonts family.
  Licensed under the Apache License, Version 2.0.
  Proportional, included because a narrow face fits noticeably more columns
  per line on a headset panel. Not monospace, so column alignment is lost.

Both are bundled rather than downloaded at runtime so the app has no network
dependency and works with the headset offline.
